开发预览 · 本页面在你的电脑运行。NCBI 登录态、私钥、原始数据留在本机。

01 · 连接 NCBI 与本机

请先在 Chrome 登录 NCBI，展开首页 “Aspera command line instructions”。如有多个 SRA 标签页，先在下方选择。

02 · 准备 Aspera
自动按系统识别 IBM 官方安装包。安装界面的许可与系统确认由你完成。ARM 平台与 Linux 安装需核对厂商支持。
03 · 创建本机传输计划
目录内只能包含本次清单中的文件。私钥应位于此目录之外。会计算每个文件的 MD5 与 SHA-256；大型文件需要时间。
04 · NCBI 元数据代填与核验
导入的 JSON 可包含 portal_fields，按当前页面的完整字段标签映射值。仅对唯一匹配的可见字段代填；未知页面、重复标签和样本表格会停下等待核对。
在 NCBI Files 页面核对同名文件夹、文件名与大小。上传文件可能需要至少约 10 分钟才出现；最后核对公开日期、BioProject/BioSample 与 SRA metadata，再由你提交。返回的 SUB 编号不等于处理完成后的 SRR/SRP 等 accession。
