# 对话闭环：意图、执行回执与任务追踪

对话入口优先用规则识别明确操作；复杂表达交给内部 DeepSeek Harness SDK 规划，校验 JSON 意图后才映射到允许列表。规划目录逐轮隔离并在结束后删除，专属角色仍按用户和角色恢复会话。桥接只在内部网络开放，模型无站点 API、数据库或 shell 权限；异常时回退到原模型网关，授权逻辑保持不变。

- 查目录、文献、引用关系、科研分享、账号、投稿、通知与角色后，同一次业务读取的结果或错误回到聊天。页面继续用于查看完整资料。资源可以在聊天里展开用途、版本、输入输出和来源。
- 分析前核对缺失或重复的文件角色，明确执行才提交。任务受原有校验、权益和私有存储规则保护。
- 全局聊天追踪当前标签页提交的最多 8 个任务，离开分析页不丢失进度。用户可随时说“查看分析进度”，重新加载本人近期任务；刷新后主动查询仍可取回结果。成功摘要只读取工作进程写入的指标，失败展示实际原因。下载仍由原 API 校验归属。
- 公开内容、资源投稿、角色创建沿用绑定账号的签名确认；编辑后废弃浏览器中的旧确认，登录后可说“继续草稿”。文献求助可以作为独立类型发布。
- NCBI 元数据验证在对话中报告问题并提供本机助手下载。真实测序文件、私钥、NCBI 外部最终提交仍留在本机；未实现的分析方法不会生成成功回执。

部署用 `infra/docker-compose.closed-loop.yml`，配合原生产、存储、组学、对话覆盖文件。桥接和门户各读独立私有环境文件。此版本无需数据库迁移；回滚时移除最后一个覆盖和启用标记，仅切回旧门户镜像即可。

SDK 参考：[DeepSeek Harness 官方 SDK 指南](https://github.com/deepseek-ai/deepseek-harness/blob/master/docs/user/guide/python-sdk.md)。

验证脚本：`db/tests/agent-harness-rna-http.mjs` 使用关闭备用网关的隔离门户验证真实 Harness 意图和 RNAseq CSV 结果，`db/tests/agent-role-http.mjs` 验证真实角色的两轮会话，`db/tests/agent-http.mjs` 覆盖签名、越权及 GWAS/BSA 结果回执。RNAseq 工作进程兼容队列中的旧文件名，依据内容将分组表交给正确的解析器，并从产物清单的 summary 获取回执指标。若回退工作进程，保留原组学版本的镜像。
