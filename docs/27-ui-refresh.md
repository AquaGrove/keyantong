## 视觉约定

- 背景为低饱和浅纸色，正文为深绿灰，深青绿用于主要动作；警告、错误保留独立颜色。
- 中文标题与正文使用协调的无衬线字体，代码和辅助英文使用等宽字体；字体不可用时正常回退。
- 通用内容最大宽度 1200px，聊天工作台最大 960px，登录/注册为 500px 内的独立卡片。
- 主要按钮最小高度 44px，输入框文字 16px，避免移动端聚焦自动缩放；表单控件允许收缩。
- 首页保留对话优先的模块导航，不新增一级模块导航；内页提供品牌返回入口和模块链接。
- 手机端推荐问题为两列，工具/分析布局按空间折为单列。长内容允许换行，结果表格在自身区域横向滚动。
- 首页与手机端助手按钮移至内容下方，避免盖住输入框；内页助手面板限制在视口内。
- 支持键盘焦点、跳转主要内容和减少动态效果偏好。

## 代码组织

- `apps/portal/src/app/globals.css` 保留现有模块布局，删除末尾旧的 Fresh adaptive shell 补丁。
- `apps/portal/src/styles/workspace.css` 在 globals 后加载，集中维护当前视觉变量、共享组件及响应式约定；后续全站视觉修改优先在此完成。
- 未引入 UI 库或额外运行时依赖。
- 工具目录卡片改用 article + 独立标题/文档链接，避免嵌套 anchor 导致 hydration 失败。
- 首页、AI 与角色聊天支持点击发送；回车发送排除中文输入法选字事件。创建角色使用可见提交按钮。
