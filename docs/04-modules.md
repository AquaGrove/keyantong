## 2. 互动论坛与需求模块（P0）

### 2.1 目标

提供结构化科研互助场景，形成可搜索、可采纳、可入库的内容。

门户 MVP 已落地 **工具分享 / 工具求助**（file-backed，见 [17-community-tool-share.md](./17-community-tool-share.md)）；文献互助仍走合规 Issue 模板。安全基线见 [18-security-baseline.md](./18-security-baseline.md)。

### 2.2 首发版块（6–8 个，禁止首发过度细分）

| 版块 | 用途 | 建议标签示例 |
|------|------|----------------|
| 文献求助与荐源 | 检索策略、合规获取路径、荐库 | `doi` `pubmed` `中文核心` |
| 软件安装与环境 | 依赖、conda/docker、版本冲突 | `conda` `docker` `cuda` |
| 代码与脚本调试 | 报错日志、复现最小例子 | `python` `r` `error-log` |
| 分析流程咨询 | 实验设计到流程选择（非代跑全部） | `rnaseq` `variant` |
| 资源分享 | 公开数据、笔记、可复现流程 | `dataset` `protocol` |
| 平台反馈与共建 | Bug、需求、贡献讨论 | `meta` |

### 2.3 结构化发帖字段（扩展字段，论坛插件或自定义）

发帖时除标题正文外，**建议**采集：

| 字段 | 类型 | 说明 |
|------|------|------|
| `category` | enum | 版块 |
| `software_name` | string | 软件名 |
| `software_version` | string | 版本 |
| `os` | string | 操作系统 |
| `error_log` | text | 关键报错摘录 |
| `doi_or_pmid` | string | 文献标识（文献帖） |
| `organism` | string | 物种（分析相关） |
| `bounty_points` | int | 悬赏积分 |

结构化字段用于检索增强与 RAG 过滤，**必须**可被 API/Webhook 读到。

### 2.4 积分与采纳

| 事件 | 积分变化（初值，可配置） |
|------|--------------------------|
| 注册完善资料 | +10 |
| 发布合格帖 | +2 |
| 回复被采纳 | +20 + 悬赏额 |
| 优质帖入库 | +15（审核后） |
| 违规扣分/封禁 | 按规约 |

规则原则：

- 提问者可设悬赏；采纳时结算  
- 禁止刷帖脚本；异常积分人工复核  
- 积分早期 **不可提现**  

### 2.5 与自研系统集成点

- Webhook：`topic.created` / `post.created` / `accepted_answer`  
- SSO 或共享会话（成长期）  
- 只读同步用户 id、显示名、声誉到 `UserBridge`

## 3. AI 智能响应引擎（P1）

### 3.1 产品形态（重要）

**不是**独立聊天机器人首页，而是：

1. 发帖后的 **相似历史帖** 推荐  
2. 可选的 **AI 初答草稿**（标注「AI 建议，请核实」）  
3. 后台知识入库流水线  

### 3.2 功能列表

| 功能 | MVP | 说明 |
|------|-----|------|
| 相似帖 Top5 | 必须 | 含链接与摘要 |
| AI 初答 | 必须（可总开关） | 超时/失败降级为空 |
| 用户一键「采用为回复」 | 建议 | 需登录；计为用户回复或 AI 辅助标记 |
| 版主驳回入库 | 必须 | 质量闸门 |
| 独立对话页 | 禁止（MVP） | 避免与社区脱节 |

细节见 [07-rag.md](./07-rag.md)。

## 4. 软件模块 ToolHub（P2）

### 4.1 工具卡（Software Card）

```yaml
id: blast-plus
name: BLAST+
summary: 序列比对基础工具
categories: [sequence]
install:
  conda: bioconda::blast
  docker: ncbi/blast:latest
common_pitfalls:
  - PATH 未包含 blastn
  - 数据库未 download
related_topics:
  - forum://t/123
```

### 4.2 能力

- 浏览 / 搜索工具卡  
- 关联论坛高赞帖  
- 托管 `environment.yml` / `docker-compose.yml` 模板  
- 用户提交 PR 式贡献（Git + 审核）  

### 4.3 非目标

- 不做成软件破解站  
- 不在浏览器内执行任意安装脚本

## 5. 在线分析平台（P3）

### 5.1 设计原则

- **拔高维度**：通用序列处理、格式转换、基础统计可视化  
- **服务化**：一工具 = 一 API + 一镜像 + 资源限额  
- **异步**：所有可能 >2s 的计算走 Job  

### 5.2 首批工具候选（成长期再冻结 3–5 个）

| 工具 | 输入 | 输出 |
|------|------|------|
| FASTA 统计 / 清洗 | fasta | json + 报告 |
| 序列长度分布图 | fasta | png/svg |
| 表格基础描述统计 | csv/tsv | json + 图 |
| 格式转换（少量） | 指定格式对 | 文件 |
| QC 摘要（轻量） | fastq 小样本 | html/json |

**禁止首批**：全基因组组装、大规模比对、需要 GPU 的深度学习流水线。

### 5.3 资源限额（默认）

| 项 | 默认 |
|----|------|
| 上传大小 | ≤ 50MB（可按用户等级调整） |
| 超时 | 10–15 min |
| CPU | 1–2 核 |
| 内存 | 2–4 GB |
| 并发/用户 | 1–2 |

## 6. 扩展与贡献体系（P4）

### 6.1 贡献类型

| 类型 | 产物 | 审核 |
|------|------|------|
| 知识 | 优质帖、FAQ、笔记 | 版主 |
| 工具卡 | YAML/Markdown 元数据 | 维护者 |
| 环境模板 | conda/docker 文件 | 维护者 + 冒烟测试 |
| 分析工具 | OCI 镜像 + OpenAPI | 安全扫描 + 试跑 |
| 代码 | 主仓库 PR | CODEOWNERS |

### 6.2 激励

- 署名、徽章、贡献者页  
- 积分与声誉  
- 工具页展示作者  

规范见 [12-contribution.md](./12-contribution.md)。

## 7. 门户 Portal（贯穿）

### 7.1 MVP 页面

- 首页：品牌、一句话定位、进入论坛 CTA、热门帖摘要  
- 关于 / 社区规约 / 合规说明  
- （可选）智能初答说明页  

### 7.2 设计约束

遵循产品前端原则：第一屏品牌清晰、信息克制；论坛内容用嵌入或 API 聚合，避免做成杂乱仪表盘。
